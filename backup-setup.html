☁️ GlucoScan — Google Sheets Backup

Set up a private, automatic backup of all your readings to Google Sheets. Your data stays in your own Google account — nobody else can see it.

✅ How it works: Every time you save a reading, the app sends a copy to your private Google Sheet. If you lose your phone data, you can restore everything from the sheet.

Setup Steps

1 Create a Google Sheet
  1. Go to sheets.new in your browser
  2. Rename it to something like "GlucoScan Backup"
  3. In Row 1, add these headers:
    ID | Timestamp | Value | Tag | Source
  4. Copy the Sheet ID from the URL:
    docs.google.com/spreadsheets/d/{SHEET_ID}/edit
2 Open Apps Script
  1. In your sheet, click Extensions → Apps Script
  2. Delete any default code in the editor
  3. Paste the entire code from backup-script.gs
3 Configure the Script
  1. In the script editor, find these two lines at the top:
const SHEET_ID = 'YOUR_GOOGLE_SHEET_ID_HERE';
const SECRET_TOKEN = 'YOUR_SECRET_TOKEN_HERE';
  1. Replace YOUR_GOOGLE_SHEET_ID_HERE with the Sheet ID from Step 1
  2. Replace YOUR_SECRET_TOKEN_HERE with a random string — make it unique! Example: glu-3a7f-k9x2
Your token is like a password — keep it secret. Only you and the GlucoScan app need it.
4 Deploy the Web App
  1. Click Deploy → New deployment
  2. Click the gear icon ⚙️ and choose Web app
  3. Set:
    • Execute as: Me
    • Who has access: Anyone
  4. Click Deploy
  5. Authorize the app (it only accesses your sheet)
  6. Copy the Web App URL that appears
"Anyone" access is fine because the script checks the secret token. Without the token, nobody can read or write your data.
5 Connect GlucoScan
  1. Open the GlucoScan app on your phone
  2. Go to Settings → Backup to Google Sheets
  3. Paste the Web App URL from Step 4
  4. Enter your Secret Token
  5. Tap Save — you're done! ✅

What Happens Next

  • Auto-sync: Every reading you save is sent to your sheet immediately
  • Restore: In Settings, tap "Restore from Backup" to pull all readings from your sheet
  • No data loss: Even if you clear your phone, your readings live in the sheet forever
First sync test: After setup, save one reading and check your Google Sheet. A new row should appear within seconds.

Troubleshooting

  • "Unauthorized" error — check your secret token matches between the script and the app
  • "Script not found" — make sure you deployed the web app and copied the right URL
  • Network error — check your internet connection
  • Data not appearing in sheet — check the sheet has headers in Row 1
